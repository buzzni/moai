moai writes each issue as one line in .moai/issues.jsonl. It is committed with your code, rides your branches and merges with them. The agent in your next session reads the same file you do, so you spend less time digging through chat logs for what was decided last week.

Run as many agents as you like.
There is still one list.

A web tracker sits outside the repository, where agents have a hard time reading it, and a Markdown TODO list stops being trusted somewhere around the third session. moai is for the space in between.

01

One line, one issue.

issues.jsonl is JSON lines sorted by id. Nothing is replayed to work out where things stand: what the file says is the state. When two branches touch different issues, the merge driver merges them issue by issue, three-way.

moai merge-driver --install   # once per clone
A6 · screenshotgit diff with a single changed line in issues.jsonl
02

It tells you. It does not stop you.

Creating and moving work needs no approval. moai status points out that you started too much at once or that a review has stalled, and refuses nothing.

A tool that fails on warnings is a tool agents learn to route around. So the warnings stay on screen.

moai defer <id> -m 'next quarter'   # column and kind stay as they were
moai defer <id> --undo              # the same line comes back
03

In a shape agents can read.

Every command takes --json. moai ready --json splits the answer into work you can pick up, work that belongs to someone else, and work on hold. moai init writes the commands and the rules into AGENTS.md, and moai skill install adds skills and hooks.

04

Many sessions, one repository.

With --from todo, a move only happens if the column is still the one you saw. The session that arrives late gets a non-zero exit and moves on. moai run inside a worktree writes to the main checkout's tracker, so the tracker never conflicts on merge.

To take over someone else's work, ask first, then take it with --take. A note keeps whose it was.

A2 · GIFTwo sessions grabbing the same issue at once. One moves it, the other gets a single stale line and backs off
05

In the terminal, or in a browser tab.

moai tui puts the list and the detail on one screen. SPC g b turns it into a kanban with a lane per milestone, and SPC g w opens the wiki under docs/. Keyboard and mouse both work.

For teammates who would rather not live in a terminal, moai web serves the same view in a browser tab. It only reads, and never writes the tracker.

A4 · GIFmoai tui switching from the list to the kanban with SPC g b, milestone lanes in view
06

A place for what you are not doing now.

Ideas that come up mid-task go into the backlog. They stay off the board and out of ready, so they do not blur the plan. When the time comes, unfold one into an epic and issues.

moai backlog add 'what if the board could fold by epic'
moai backlog promote <id> --from -
07

While a milestone runs, it comes first.

A milestone is running as soon as one of its members is picked up. There is no command to open it. Until it ships, moai ready hands out its work first and only p0 from outside. As deadlines get close, moai due apply raises priorities.

A5 · screenshotThe moai web board in one browser tab, milestone lanes and cards
08

One supervisor, several workers.

In Claude Code, the session that calls /moai-supervise hands the piled-up backlog to idle sessions one at a time and takes their reports. Inside tmux or cmux it can clear a worker's window, and open a new one once you say yes.

The moai binary never launches an agent. A person always opens the session.

The first five minutes.

  1. moai init creates .moai/ and writes how to use it into AGENTS.md.
  2. Add an issue, then see what is next with moai ready.
  3. Pick it up, leave a note, close it. The next session reads the note with moai show.
  4. Working with agents? moai skill install adds the skills and hooks.
first five minutes
$ moai init
$ moai add 'the board wraps at 80 columns' -t bug -p 1
$ moai ready
$ moai mv <id> in_progress
$ moai note <id> 'the width comes from view.rs, not the terminal'
$ moai mv <id> done

Start your next session
with moai status.

Installing is one line. Run the same line later and it upgrades what is there.

$ curl -fsSL https://raw.githubusercontent.com/buzzni/moai/main/install.sh | sh

On Windows, use install.ps1.
