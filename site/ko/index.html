터미널과 웹에서 진행 사항을 손쉽게 확인하세요.

moai는 손에 익은 단축키와 사용성 높은 UI를 제공하고 있습니다.

01

모든 화면을 터미널 하나에서.

목록, 마일스톤별 칸반, 위키를 한 화면에서 오갑니다. 커서가 가리키는 일의 상세는 늘 옆에 떠 있습니다. 터미널이지만 마우스까지 완벽하게 지원합니다.

터미널$ moai tui

moai tui
02

기존 이슈 트래커와 견주어도 전혀 부족함이 없습니다.

상세한 작업 지시서, 작업 도중에 남긴 메모, 커밋과 일정까지 한눈에 확인 가능합니다.

브라우저$ moai web

127.0.0.1:6624
03

문서를 남기기 위해 또 다른 제품을 사용하지 마세요.

에이전트가 일하면서 moai에 내장된 위키에 문서를 작성합니다. 원하는 부분 또는 전체에 대한 내용을 손쉽게 생성할 수 있으며 에이전트가 요긴하게 참고합니다.

브라우저$ moai web

127.0.0.1:6624
04

일의 진척도와 흐름이 한눈에 보입니다.

사용자의 아이디어가 백로그에서 시작하여 마일스톤, 에픽에서 태스크로 업무가 나누어지고, 리뷰와 완료까지 모든 것을 에이전트가 알아서 옮기며 진행합니다.

터미널$ moai tui

moai tui

일할 자리를 주세요.
