에이전트가 여러 개 돌아도
할 일 목록은 하나입니다.

웹 트래커는 저장소 밖에 있어서 에이전트가 읽기 어렵고, 마크다운 TODO는 세 번째 세션쯤 되면 아무도 믿지 않습니다. moai는 그 사이를 메우려고 만들었습니다.

01

한 줄이 이슈 하나.

issues.jsonl은 id 순으로 정렬된 JSON 줄입니다. 상태를 알려고 이벤트를 다시 접지 않습니다. 파일에 적힌 것이 지금 상태입니다. 서로 다른 이슈를 고친 두 브랜치는 머지 드라이버가 이슈 단위로 3-way 머지합니다.

moai merge-driver --install   # 클론마다 한 번
A6 · 스크린샷git diff에서 issues.jsonl 한 줄만 바뀐 모습
02

막지 않고 알려 줍니다.

만드는 것도 옮기는 것도 승인이 필요 없습니다. moai status는 한꺼번에 벌여 놓은 일이 많다거나 리뷰가 오래 멈췄다고 말해 줄 뿐, 아무것도 거절하지 않습니다.

경고로 실패하는 도구는 에이전트가 금방 우회할 대상이 됩니다. 그래서 경고는 화면에만 남깁니다.

moai defer <id> -m '다음 분기'   # 칸도 종류도 그대로
moai defer <id> --undo          # 같은 줄이 그대로 돌아온다
03

에이전트가 읽는 형식으로.

모든 명령이 --json을 받습니다. moai ready --json은 지금 집을 일, 남의 일, 미뤄 둔 일을 나눠서 돌려줍니다. moai init은 AGENTS.md에 명령과 판단 기준을 적고, moai skill install은 스킬과 훅을 심습니다.

A7 · 스크린샷훅이 남의 이슈 집기를 거절하고, 고칠 명령(--take)을 그대로 내주는 장면
04

세션 여럿, 저장소 하나.

--from todo를 붙이면 본 칸이 그대로일 때만 옮깁니다. 늦게 온 세션은 0이 아닌 코드를 받고 다음 일로 넘어갑니다. 워크트리 안에서 부른 moai는 본 체크아웃의 트래커에 쓰기 때문에, 머지할 때 트래커가 충돌하지 않습니다.

남의 일을 집을 때는 사람에게 먼저 묻고 --take로 넘겨받습니다. 원래 누구 것이었는지는 노트로 남습니다.

A2 · GIF두 세션이 같은 이슈를 동시에 집는 장면. 한쪽은 옮기고, 다른 쪽은 stale 한 줄을 받고 물러난다
05

터미널에서도, 브라우저에서도.

moai tui는 목록과 상세를 한 화면에 띄웁니다. SPC g b를 누르면 마일스톤별 칸반이 되고, SPC g w는 docs/의 위키를 엽니다. 키보드와 마우스 둘 다 됩니다.

터미널이 낯선 팀원에게는 moai web이 같은 화면을 브라우저 탭으로 보여 줍니다. 읽기만 하고, 트래커에는 아무것도 쓰지 않습니다.

A4 · GIFmoai tui 목록에서 SPC g b로 칸반 전환, 마일스톤 레인이 보이게
06

지금 안 할 일에도 자리가 있습니다.

작업 중 떠오른 생각은 백로그에 담습니다. 보드에도 ready에도 나오지 않아서 계획이 흐려지지 않습니다. 때가 되면 에픽과 이슈로 펼칩니다.

moai backlog add '보드를 에픽별로 접으면 어떨까'
moai backlog promote <id> --from -
07

마일스톤이 돌면 그 안부터.

마일스톤 멤버 하나가 시작되면 그 마일스톤은 도는 중입니다. 따로 여는 명령은 없습니다. 그동안 moai ready는 안쪽 일을 먼저 주고, 밖에서는 p0만 내줍니다. 마감이 다가오면 moai due apply가 우선순위를 올립니다.

A5 · 스크린샷moai web 보드. 브라우저 탭 하나, 마일스톤 레인과 카드
08

감독 하나에 일꾼 여럿.

Claude Code에서 /moai-supervise를 부른 세션이 쌓인 백로그를 놀고 있는 세션에 하나씩 보내고 보고를 받습니다. tmux와 cmux 안에서는 일꾼 창을 비우고, 사람이 허락하면 새 창도 엽니다.

moai 바이너리는 에이전트를 직접 띄우지 않습니다. 세션은 늘 사람이 엽니다.

A8 · GIFtmux 세 칸. 감독이 두 일꾼에게 일을 보내고, 일꾼이 끝낸 뒤 보고가 돌아오는 장면

처음 5분.

  1. moai init이 .moai/를 만들고 AGENTS.md에 사용법을 적습니다.
  2. 이슈를 하나 만들고 moai ready로 지금 할 일을 봅니다.
  3. 집고, 메모를 남기고, 닫습니다. 메모는 다음 세션이 moai show로 읽습니다.
  4. 에이전트를 쓰면 moai skill install로 스킬과 훅을 심습니다.
처음 5분
$ moai init
$ moai add 'the board wraps at 80 columns' -t bug -p 1
$ moai ready
$ moai mv <id> in_progress
$ moai note <id> 'the width comes from view.rs, not the terminal'
$ moai mv <id> done

다음 세션은
moai status로 시작하세요.
