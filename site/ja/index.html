moai はイシューを .moai/issues.jsonl に1行ずつ書きます。コードと一緒にコミットされ、ブランチに乗り、マージされます。次のセッションのエージェントも、明日の自分も、同じファイルを読みます。前に何を決めたのか、チャットの履歴を掘り返す手間が減ります。

$ curl -fsSL https://raw.githubusercontent.com/buzzni/moai/main/install.sh | sh

エージェントがいくつ動いていても、
やることリストはひとつ。

Web のトラッカーはリポジトリの外にあってエージェントからは読みにくく、Markdown の TODO は3つ目のセッションあたりで誰も信じなくなります。moai はその間を埋めるために作りました。

01

1行が1イシュー。

issues.jsonl は id 順に並んだ JSON の行です。いまの状態を知るためにイベントを再生することはありません。ファイルに書かれていることが、いまの状態です。別々のイシューを触った2つのブランチは、マージドライバがイシュー単位で3-way マージします。

moai merge-driver --install   # クローンごとに1回
A6 · スクリーンショットgit diff で issues.jsonl の1行だけが変わった様子
02

止めずに、知らせる。

作るのにも動かすのにも承認はいりません。moai status は、同時に抱えすぎている、レビューが長く止まっている、と教えるだけで、何も拒みません。

警告で失敗するツールは、エージェントにすぐ迂回されます。だから警告は画面に出すだけにしています。

moai defer <id> -m '来期に回す'   # カラムも種類もそのまま
moai defer <id> --undo           # 同じ行がそのまま戻る
03

エージェントが読める形で。

どのコマンドも --json を受け付けます。moai ready --json は、いま取れる仕事、ほかの人の仕事、保留中の仕事に分けて返します。moai init は AGENTS.md にコマンドと判断の基準を書き、moai skill install はスキルとフックを入れます。

04

セッションは複数、リポジトリはひとつ。

--from todo を付けると、見たときのカラムのままのときだけ移動します。遅れて来たセッションは0以外の終了コードを受け取り、次の仕事へ移ります。worktree の中で呼んだ moai はメインのチェックアウトのトラッカーに書くので、マージでトラッカーが衝突しません。

ほかの人の仕事を取るときは、先に本人に聞いてから --take で引き継ぎます。もとが誰のものだったかはノートに残ります。

A2 · GIF2つのセッションが同じイシューを同時に取りに行く場面。片方は移動し、もう片方は stale の1行を受け取って引き下がる
05

ターミナルでも、ブラウザでも。

moai tui は一覧と詳細を1画面に出します。SPC g b でマイルストーンごとのカンバンになり、SPC g w で docs/ の wiki を開きます。キーボードでもマウスでも操作できます。

ターミナルに慣れていないメンバーには、moai web が同じ画面をブラウザのタブで見せます。読むだけで、トラッカーには何も書きません。

A4 · GIFmoai tui の一覧から SPC g b でカンバンに切り替え。マイルストーンのレーンが見えるように
06

いまやらないことにも、置き場所がある。

作業中に思いついたことはバックログに入れます。ボードにも ready にも出ないので、計画がぼやけません。時期が来たら、エピックとイシューに展開します。

moai backlog add 'エピックごとにボードを畳めたら'
moai backlog promote <id> --from -
07

マイルストーンが動いている間は、その中から。

マイルストーンのメンバーがひとつ着手されれば、そのマイルストーンは進行中です。開くためのコマンドはありません。その間 moai ready は中の仕事を先に渡し、外からは p0 だけを出します。締め切りが近づくと moai due apply が優先度を上げます。

A5 · スクリーンショットmoai web のボード。ブラウザのタブ1枚に、マイルストーンのレーンとカード
08

監督ひとりに、作業者が何人か。

Claude Code で /moai-supervise を呼んだセッションが、たまったバックログを手の空いているセッションにひとつずつ渡し、報告を受け取ります。tmux や cmux の中では作業者のウィンドウを片付け、許可があれば新しいウィンドウも開きます。

moai のバイナリがエージェントを直接起動することはありません。セッションを開くのはいつも人です。

A8 · GIFtmux の3ペイン。監督が2人の作業者に仕事を送り、報告が戻ってくる場面

最初の5分。

  1. moai init が .moai/ を作り、AGENTS.md に使い方を書きます。
  2. イシューをひとつ作り、moai ready でいまやることを見ます。
  3. 着手して、メモを残して、閉じます。メモは次のセッションが moai show で読みます。
  4. エージェントを使うなら、moai skill install でスキルとフックを入れます。
最初の5分
$ moai init
$ moai add 'the board wraps at 80 columns' -t bug -p 1
$ moai ready
$ moai mv <id> in_progress
$ moai note <id> 'the width comes from view.rs, not the terminal'
$ moai mv <id> done

次のセッションは
moai status から。

インストールは1行です。もう入っていれば、同じ1行で新しい版に上がります。

$ curl -fsSL https://raw.githubusercontent.com/buzzni/moai/main/install.sh | sh
