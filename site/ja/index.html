ベンダーが違っても、ひとつのチームで。

ベンダーの違うエージェントも、監督と作業者に分かれて一緒に働きます。監督は手の空いた作業者に残りの仕事を配り、いくつもの作業を同時に進めます。作業者は必要なだけ立ち上げてください。それぞれが自分の worktree で作業するのでぶつからず、監督が間に立って最後まで仕上げます。

  • 指示はひと言で十分です。たまったバックログを、手の空いたセッションに配って。
  • 作業者のウィンドウを片付け、次の仕事を送り、報告を確かめるところまで監督がやります。
  • 計画は Claude Fable、開発は Codex Sol、雑務は Antigravity Gemini、レビューは Claude Opus に。仕事ごとに得意なモデルへ任せてみてください。

Moai と共に動くプロダクト

01

すべての画面を、ターミナルひとつで。

一覧、マイルストーンごとのカンバン、wiki を1画面で行き来します。カーソルの下にある仕事の詳細は、いつも横に出ています。ターミナルなのに、マウスも完全に使えます。

ターミナル$ moai tui

moai tui
02

既存のイシュートラッカーと比べても、引けを取りません。

詳しい作業指示、作業の途中で残したメモ、コミットと日程まで、ひと目で確認できます。

ブラウザ$ moai web

127.0.0.1:6624
03

ドキュメントのために、別の製品を使うのはやめましょう。

エージェントは作業しながら、moai に内蔵された wiki に文書を書きます。一部でも全体でも手軽に書かせることができ、エージェントはそれを頼りに動きます。

ブラウザ$ moai web

127.0.0.1:6624
04

仕事の進み具合と流れが、ひと目でわかる。

ユーザーのアイデアはバックログから始まり、マイルストーン、エピックからタスクへと分けられ、レビューと完了まで、エージェントがすべて自分で動かして進めます。

ターミナル$ moai tui

moai tui
