## moai v0.39.0
### What's new
- `moai ctl ls` finds your open explorers and web tabs; `moai ctl state` reads what one shows.
- `moai ctl keys` presses keys, while `do` runs named actions listed by `actions`.
- `moai ctl sort`, `filter`, `find`, and other named verbs change an open view immediately.
- The same controls reach visible `moai web` tabs, including their sort, filter, and theme.
- `moai ctl propose` shows a suggestion in the explorer or web tab for the person to accept or decline.
- Web views now follow tracker changes through a live event stream, with polling as a fallback.
