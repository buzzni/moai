## moai v0.44.0
### What's new
- **Pictures in the explorer** — in kitty and Ghostty, an issue's detail and the wiki pane now draw the pictures added with `moai image add`, scrolling with the text; other terminals keep the placeholder and a clickable link
### Fixes
- A kitty window opened from a shell inside tmux now draws pictures; a real tmux pane keeps the text placeholder
