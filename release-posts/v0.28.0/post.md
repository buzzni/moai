## moai v0.28.0
### What's new
- **`?` (or `SPC h`) in the explorer opens a window that lists every key**, in one to three columns by the size of the screen
- **`SPC h` in the explorer opens the key list instead of closing the menu and folding the row**, and `?` is now a key of its own

Thanks to @hedone21 for the key list — this release is their PR #50: <https://github.com/buzzni/moai/pull/50>

Upgrading: a `keys.toml` line that put `?` or `SPC h` on another action is now dropped as a clash — move it to another key.

Release notes: <https://github.com/buzzni/moai/releases/tag/v0.28.0>
Update with `moai update` · install: <https://moai.buzzni.com/guide/#install>
