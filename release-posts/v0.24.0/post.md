## moai v0.24.0
### What's new
- **Any row can carry a planned start, not only a milestone**
- **A plan line can end in `@start~deadline`**
- **A gantt layout in the explorer — `SPC g g`**
- **`-` `=` `+` `H` `L` `[` `]` `t` `z` `<` `>` `{` `}` are now the gantt's keys in the explorer**
- **`starts_on` is no longer refused on rows that are not milestones**
- **Claude workers no longer go into their worktree**
- …and 1 more in the release notes
### Fixes
- `moai backlog promote` left its history notes in Korean whatever the screen language
- The backlog title `promote` copies into that note is folded onto one line
