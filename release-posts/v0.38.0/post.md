## moai v0.38.0
### What's new
- Explorer and web lists open active milestones and fold completed ones; epics stay open, and board epic cards are gone
- TUI board cards use black head bands with status-coloured text and reverse the band on the selected card
- Todo is blue across TUI and web views; selected web list rows have a stronger left marker
### Fixes
- Web Gantt date headers, weekend shading and lanes now extend across a wide or resized pane even when work spans only a few days
- Explorer overview entry and return now seed closed milestone folds for board and Gantt layouts, while leaving running milestones open

Release notes: <https://github.com/buzzni/moai/releases/tag/v0.38.0>
