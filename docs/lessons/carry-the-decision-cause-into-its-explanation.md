# Carry the decision cause into its explanation

## What happened

- A guard excluded a child through an ancestor, but its explanation guessed a new cause from the child's own records.
- Two blocks in one refusal offered incompatible actions; an inferred lack of a record could offer a command that claimed another session's work.

## Why

- Classification and explanation independently reconstructed the same decision from different inputs.
- Recomputing focus also lost rows counted from an earlier action in the same command.

## Do this instead

- Return the exclusion cause and its source with the decision; let every explanation and recovery action consume that cause.
- Preserve the actual inputs counted by the guard, including simulated preceding actions, instead of reconstructing them later.
- Test the complete refusal for contradictory actions and inherited causes, alongside tests for individual lines.
