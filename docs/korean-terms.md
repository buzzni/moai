# 한국어 용어표

이 저장소의 한국어 글에 쓰는 기술 용어를 고정한다. 이슈 제목과 본문, 노트, 커밋
메시지, `CLAUDE.md`, 그리고 `src/**/*.rs` 의 한국어 doc comment 가 대상이다. 코드
곁의 주석이야말로 읽는 쪽이 코드로 되돌아가야 하는 곳이라 뺄 수 없다. `i18n/ko.json`
의 화면 글은 폭 제한이 따로 있어 여기서 다루지 않는다.

**왜 필요한가.** 기술 용어를 고유어 일반명사로 옮기고 원어를 지우면 읽는 쪽이
코드로 되돌아갈 길이 없다. 고유어 일반명사는 뜻이 여러 개라, 한 낱말이 서로 다른
것을 가리키기 시작하면 문맥만으로 복원되지 않는다. 2026-09-22 에
`grep -o` 로 `.moai/issues.jsonl` 을 세어 보니 `층` 266회에 `레이어` 0회였고
`자리` 1252회가 position, slot, place, site 를 한꺼번에 덮고 있었다. 같은 날
`src/` 의 doc comment 는 `층` 954회에 `자리` 4290회로, 트래커보다 3배 넘게 짙었다.

## 1. 옮기지 않는다 — 코드에서 온 이름

타입, 함수, 상수, 변형, 필드, 파일 경로, 명령, 플래그는 원어 그대로 적는다.

    `latest::Seen::Unasked`  `tui::layer::summarize`  `PROBE_BUDGET`  `--from`

뜻을 덧붙이고 싶으면 원어 뒤에 괄호로 단다. 원어를 지우고 뜻만 남기지 않는다.

- 쓴다: `Seen::Unasked`(한 번도 묻지 못한 상태)
- 쓰지 않는다: "못 물었다"

## 2. 표준 표기를 쓴다 — 일반 기술 용어

**막는 칸은 그 뜻에서만 막는다.** `값`·`잰`·`심는다` 는 다른 뜻으로는 멀쩡한 말이다 —
`파생값`·`기본값` 은 value 라 그대로 쓰고, 블록과 훅을 저장소에 **심는** 것도 그대로다.

| 원어 | 쓴다 | 이 뜻으로는 쓰지 않는다 |
|---|---|---|
| layer | 레이어 | 층 |
| network | 네트워크 | 그물 |
| wrapper | 래퍼 | 감싸는 명령 |
| loopback | 루프백 | 되돌이 |
| process, subprocess | 프로세스, 하위 프로세스 | 띄우는 것 |
| machine | 기계 | 머신 |
| proxy, certificate | 프록시, 인증서 | |
| cache, timeout | 캐시, 타임아웃 | |
| install (플러그인·도구를) | 설치한다, 깐다 | 심는다 |
| measure, measured value | 측정한다, 측정값 | 잰 값 |
| contention, race | 경합 | 겨룸 |
| cost | 비용 | 값 |

`판` 과 `자리` 는 한 낱말이 여러 뜻을 덮고 있으니 문맥에 맞는 말로 갈라 쓴다. 3절이
`칸` 과 `줄` 을 다른 뜻으로 묶어 두었으니 그 둘은 갈라 쓸 후보에서 뺀다.

- 판 → 실행, 빌드, 릴리스, 버전, 회차
- 자리 → 위치, 지점, 곳, 슬롯

## 3. 이 저장소에서 굳은 말 — 그대로 쓴다

화면 글(`i18n/ko.json`)이 이미 쓰고 있어 뜻이 하나로 굳은 말이다. 바꾸지 않는다.

| 뜻 | 쓴다 |
|---|---|
| status column | 칸 |
| issue row, file line | 줄 |
| pick up | 집는다 |
| defer | 미룬다, 미룸 |
| epic, milestone, worktree, project, board | 에픽, 마일스톤, 워크트리, 프로젝트, 보드 |

**화면이 `층` 이라고 찍는 곳은 2절의 `layer` 줄과 겹친다.** 탐색기의 프로젝트 레이어를
`i18n/ko.json` 은 `프로젝트 층`·`한 층 위로` 로 찍는다(`tui.layer.*` 키 일곱). 가르는 법은
1절이 이미 준다 — **모듈을 말하면 모듈 이름을 적고**(`tui::layer`), **화면에 뜬 글을
말하면 그 글을 그대로 따온다**(`프로젝트 층`). 남는 산문에서만 `레이어` 를 쓴다.

## 4. 첫 등장에 원어를 병기한다

한 이슈 본문에서 **2절의 일반 기술 용어**가 처음 나올 때 괄호로 원어를 붙이고
그다음부터는 한국어만 쓴다.

- 레이어(layer) 요약이 프로젝트마다 하위 프로세스를 부른다. 그 레이어는 ...

**1절의 코드에서 온 이름은 여기 들지 않는다.** 그것은 옮길 용어가 아니라 이름이라
나올 때마다 그대로 적고, 괄호는 원어 **뒤**에 뜻을 다는 데 쓴다. 이 절을 코드 이름에
대면 `못 물었다(Seen::Unasked)` 가 되고 "그다음부터는 한국어만" 이 이름을 지운다 —
이 표가 막으려던 바로 그 일이다.

## 5. 주어와 목적어를 지우지 않는다

조사만 남기고 주어와 목적어를 줄이면 문장이 무너진다.

- 쓰지 않는다: 층이 줄마다 git 을 띄운다
- 쓴다: `tui::layer::summarize` 가 프로젝트 줄마다 하위 프로세스를 새로 실행한다

- 쓰지 않는다: 회사 그물의 프록시가 인증서를 갈아 끼우면 영영 "못 물었다"로 선다
- 쓴다: 사내 네트워크의 프록시가 인증서를 갈아 끼우면 검증이 실패해, 그 기계는
  `Seen::Unasked` 상태에 그대로 머문다

## 이미 쓴 글은 고치지 않는다

이슈 1126건(2026-09-22 의 `kind: issue` 수)도, `CLAUDE.md` 와 `src/` 의 doc comment 도
소급해 고치지 않는다. 비용에 비해 이력만 흔든다. 이 표는 **앞으로 쓰는 글**에 적용하고,
이미 선 글에 남은 옛 낱말은 어긋난 것이 아니라 손대지 않은 것이다. 그러니 이 표를 들고
사전 치환을 한 회차 돌리지 않는다 — 고치는 것은 그 줄을 어차피 다시 쓸 때뿐이다.
