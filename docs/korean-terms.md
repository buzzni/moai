# 한국어 용어표

이 저장소의 한국어 글에 쓰는 기술 용어를 고정한다. 이슈 제목과 본문, 노트, 커밋
메시지, `CLAUDE.md` 가 대상이다. `i18n/ko.json` 의 화면 글은 폭 제한이 따로 있어
여기서 다루지 않는다.

**왜 필요한가.** 기술 용어를 고유어 일반명사로 옮기고 원어를 지우면 읽는 쪽이
코드로 되돌아갈 길이 없다. 고유어 일반명사는 뜻이 여러 개라, 한 낱말이 서로 다른
것을 가리키기 시작하면 문맥만으로 복원되지 않는다. 2026-09-22 에 세어 보니
`층` 266회에 `레이어` 0회였고 `자리` 1252회가 position, slot, place, site 를
한꺼번에 덮고 있었다.

## 1. 옮기지 않는다 — 코드에서 온 이름

타입, 함수, 상수, 변형, 필드, 파일 경로, 명령, 플래그는 원어 그대로 적는다.

    `latest::Seen::Unasked`  `layer::summarize`  `PROBE_BUDGET`  `--from`

뜻을 덧붙이고 싶으면 원어 뒤에 괄호로 단다. 원어를 지우고 뜻만 남기지 않는다.

- 쓴다: `Seen::Unasked`(한 번도 묻지 못한 상태)
- 쓰지 않는다: "못 물었다"

## 2. 표준 표기를 쓴다 — 일반 기술 용어

| 원어 | 쓴다 | 쓰지 않는다 |
|---|---|---|
| layer | 레이어 | 층 |
| network | 네트워크 | 그물 |
| wrapper | 래퍼 | 감싸는 명령 |
| loopback | 루프백 | 되돌이 |
| process, subprocess | 프로세스, 하위 프로세스 | 띄우는 것 |
| proxy, certificate | 프록시, 인증서 | |
| cache, timeout | 캐시, 타임아웃 | |
| install | 설치한다 | 심는다 |
| measure, measured value | 측정한다, 측정값 | 잰 값 |
| contention, race | 경합 | 겨룸 |
| cost | 비용 | 값 |

`판` 과 `자리` 는 한 낱말이 여러 뜻을 덮고 있으니 문맥에 맞는 말로 갈라 쓴다.

- 판 → 실행, 빌드, 릴리스, 버전, 회차
- 자리 → 위치, 지점, 칸, 줄, 슬롯

## 3. 이 저장소에서 굳은 말 — 그대로 쓴다

화면 글(`i18n/ko.json`)이 이미 쓰고 있어 뜻이 하나로 굳은 말이다. 바꾸지 않는다.

| 뜻 | 쓴다 |
|---|---|
| status column | 칸 |
| issue row, file line | 줄 |
| pick up | 집는다 |
| defer | 미룬다 |
| epic, milestone, worktree, project, board | 에픽, 마일스톤, 워크트리, 프로젝트, 보드 |

## 4. 첫 등장에 원어를 병기한다

한 이슈 본문에서 기술 용어가 처음 나올 때 괄호로 원어를 붙이고 그다음부터는
한국어만 쓴다.

- 레이어(layer) 요약이 프로젝트마다 하위 프로세스를 부른다. 그 레이어는 ...

## 5. 주어와 목적어를 지우지 않는다

조사만 남기고 주어와 목적어를 줄이면 문장이 무너진다.

- 쓰지 않는다: 층이 줄마다 git 을 띄운다
- 쓴다: `layer::summarize` 가 프로젝트 줄마다 하위 프로세스를 새로 실행한다

- 쓰지 않는다: 회사 그물의 프록시가 인증서를 갈아 끼우면 그 기계는 영영 "못 물었다"로 선다
- 쓴다: 사내 네트워크의 프록시가 인증서를 갈아 끼우면 검증이 실패해, 그 머신은
  `Seen::Unasked` 상태에 영구히 머문다

## 이미 쓴 글은 고치지 않는다

이슈 1126건을 소급해 고치지 않는다. 비용에 비해 이력만 흔든다. 이 표는 앞으로
쓰는 글에 적용한다.
